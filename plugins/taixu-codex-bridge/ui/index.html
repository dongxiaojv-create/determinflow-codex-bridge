Codex Bridge

先在终端运行 codex login，通过官方浏览器页面登录自己的账户。此插件不接收密码，也不上传登录凭据。

插件复用当前系统用户的 Codex CLI 登录，模型调用会消耗该账户额度。更换账户请在终端运行 codex logout 后重新登录。

找不到 CLI 时，在插件设置填写 codex_path；需要代理时填写 proxy，保存后重启 DeterminFlow。

尚未检查账户。检查和刷新目录不发送模型生成请求。

刷新目录后重启 DeterminFlow，再在模型菜单选择 Codex Bridge。未登录时请先完成官方登录。
